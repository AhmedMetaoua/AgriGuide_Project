# Frontend

Interface générée/itérée via Lovable (voir prompt dans docs de conversation
d'équipe). Consomme l'API de l'orchestrateur (`backend/orchestrator/`) comme
point d'entrée unique pour le chat, et les endpoints REST des agents pour
les données structurées (dashboards, marketplace, etc).

## Écrans principaux
Voir `docs/ARCHITECTURE.md` et le prompt Lovable pour la liste complète des
écrans (onboarding, dashboard, 3 advisors, suivi quotidien, marketplace).
